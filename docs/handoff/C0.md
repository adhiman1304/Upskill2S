## Import paths for workstreams B, C, D and E

From a page file at `client/src/pages/<area>/X.tsx`:

```ts
import { useApi, useSession } from '../../session'
import { apiRequest, ApiError, type AuthenticatedRequest } from '../../lib/api/client'
import type { BriefPageDto, JobDto, StudyBriefContent, IntakeSessionDto, IntakeResult, OpenAiKeyStatusDto, CatalogHitDto, FreshnessStatus, ApiErrorCode } from '../../lib/contracts'
import { usePolling } from '../../hooks/usePolling'
import { featuredProviders, providerLogoDomains, ProviderLogo } from '../../pages/legacy/providers'  // D: from pages/home use '../legacy/providers'
```

From a feature API module at `client/src/lib/api/<feature>.ts`:

```ts
import type { AuthenticatedRequest } from './client'
import type { JobDto } from '../contracts'
export function getJob(request: AuthenticatedRequest, id: string) { return request<JobDto>(`/api/jobs/${encodeURIComponent(id)}`) }
```

Conventions:
- API functions take the `request` from `useApi()` as their first argument, as `legacy.ts` does. Do not call `apiRequest` directly from pages: it sends no Entra token.
- Error codes: `if (error instanceof ApiError && error.code === 'OPENAI_KEY_MISSING') ...` (`error.status` is also available).
- `usePolling`: the next poll starts only after the previous one finishes, so requests never overlap. The latest `fetcher` is always used, so an inline arrow is fine. Pass `enabled = false` to stop (for example once `job.status` is `SUCCEEDED`, `FAILED` or `CANCELLED`); `data` keeps its last value, and `error` is an `Error | null`. `refresh()` fetches once right away and returns the result or `null`. Example: `const { data: job } = usePolling(() => getJob(request, jobId!), 2000, Boolean(jobId) && !done)`.
- Shared legacy UI helpers you may reuse: `message()` and `formatDate()` in `pages/legacy/utils.ts`; CSS classes `page-content`, `topbar`, `breadcrumb`, `button button-primary|secondary|quiet`, `alert error`, `empty-state`, `loading-state`, `eyebrow`, `muted`, `section-heading`.

## Deviations and notes for the integrator

1. **My certifications** is a plain `Link` to `{ pathname: '/', hash: 'mine' }`, not a `NavLink`. That avoids two links being highlighted on `/`. **D: put `id="mine"` on the My certifications section of Home** so the link jumps to it. Scrolling is not automatic: if wanted, D can add `useEffect(() => { if (location.hash === '#mine') document.getElementById('mine')?.scrollIntoView() }, [location.hash])`.
2. **ApiKeyBanner** checks `GET /api/settings/openai-key` on mount and checks again after the user leaves `/settings`, so saving a key clears the banner without a reload. It shows only when the response has `configured === false`, renders nothing on `/settings`, and stays silent on any error.
3. **Legacy dialogs** for creating or editing a certification and adding a resource now belong to the page that opens them, instead of the old top-level `Portal` state. After a save, the detail page reloads its certification instead of remounting the component. Creating a certification goes to its `/library/:id` page, as before.
4. `session.tsx` and `providers.tsx` export both components and non-components, so each starts with an `eslint-disable react-refresh/only-export-components` comment.
5. Not every legacy flow could be tested against the API. Port 5173 was already taken by the main checkout's dev server (`/Users/martin/Developer/study_guide_center/client`), which I left running, so I used port 5174. The API on port 4000 only allows CORS from `http://localhost:5173`, so on 5174 the legacy pages showed their normal "Failed to fetch" error states.
   - All routes rendered with the correct shell and active highlighting: `/`, `/intake`, `/library`, `/library/:id`, `/community`, `/settings`, `/admin/ops`, and an unknown path that redirected to `/`.
   - The console showed only those CORS network errors, no React or runtime errors. The mobile bottom bar also renders.
   - **Not done: a full click-through of the legacy flows (open, edit, add resource, delete, bookmark) against a live API on 5173.**
